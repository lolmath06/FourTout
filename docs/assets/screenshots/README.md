# Captures d'écran

Captures utilisées par le `README.md` et par la page de publication.

## Ce qu'il faut

| Fichier | Écran |
| --- | --- |
| `accueil.png` | Accueil — « Que voulez-vous faire ? », favoris, catégories |
| `outils.png` | Page Outils — les dix catégories |
| `pdf-fusion.png` | Un outil PDF en cours d'utilisation |
| `video.png` | Un outil vidéo, avec progression |
| `fichiers.png` | Un outil de fichiers (arborescence ou doublons) |
| `developpeur.png` | Un outil développeur (JSON ou regex) |
| `parametres.png` | Paramètres — apparence, taille de l'interface |

## Règles

- **Aucune donnée personnelle visible.** Utilisez les fixtures de
  `test-assets/generated/`, ou des fichiers créés pour l'occasion. Ni nom
  réel, ni chemin contenant un nom d'utilisateur, ni contenu de document
  privé.
- **Thème clair**, taille d'interface à 100 %, densité compacte : c'est la
  configuration par défaut, celle que verra le lecteur.
- **Fenêtre à 1180 × 780**, la taille par défaut de FourTout. Les captures
  restent alors comparables entre elles.
- **PNG**, sans ombre portée du bureau ni décor de fond.

Ces captures sont référencées par le `README.md` : gardez les noms de fichiers
stables.
